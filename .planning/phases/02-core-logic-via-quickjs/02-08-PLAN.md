    - Maps: equal key sets and recursive values. A key whose value is null is NOT treated as equal to an absent key; JSON already dropped undefined on both sides.
    - Lists: equal length, element-wise.
    - num vs num: exact `==` (int 5 equals double 5.0; no epsilon). On inequality of two finite doubles, compute the ULP distance via ByteData float64 bit patterns, for diagnostics only.
    - String/bool/null: `==`. Type mismatch means a diff.
