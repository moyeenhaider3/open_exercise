<objective>
Build the JS-01 pipeline: vendor exactly the openGym `frontend/src/lib` modules the bridge needs into `third_party/opengym/lib/`, and bundle them with an exact-pinned esbuild into a single IIFE Flutter asset `assets/js/opengym-lib.bundle.js` using one reproducible script, `tool/gen_js_bundle.sh`.

Purpose: `flutter_js` cannot resolve ES `import`/`export`, so openGym's module graph has to be flattened into one global before QuickJS/JavaScriptCore can run it unchanged. That is the core value: the same inputs give the same numbers.
Output: vendored sources plus a SHA-256 manifest, esbuild tooling isolated under `tool/js/`, the build script, and the committed bundle asset.
</objective>
