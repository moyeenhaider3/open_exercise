# Plan 03.1-03 Summary: Routes, Feature Provider Files, S.wdec Listener, Header Entry Points, WorkoutRowTile & Heatmap

## Overview
Laid the shared routing, DI, configuration, and presentation foundations for the five remaining screens in Phase 3.1 (`/history`, `/settings`, `/checkin`, plus updates to Home and Stats). Every Phase 3.1 feature Bloc has an isolated provider file registered in `app.dart` so subsequent plans can execute without modifying `app.dart` or `app_router.dart`. Also ported openGym's shared `WorkoutRowTile` and 53-week `Heatmap` widgets with full adherence to JS-04 and UI-08 architectural rules.

## Key Deliverables

1. **Routing & Guards (`lib/core/router/app_router.dart`)**:
   - Added named routes:
     - `AppRoutes.history = '/history'` (named 'history', building `HistoryScreen`)
     - `AppRoutes.settings = '/settings'` (named 'settings', building `SettingsScreen`)
     - `AppRoutes.checkin = '/checkin'` (named 'checkin', building `CheckInScreen`)
   - Added guard redirect:
     - When route is `/checkin` and `GymState.checkIn == false`, redirects cleanly to `/home` (mirroring `App.jsx:152`).

2. **Isolated Feature Provider Hooks (`lib/app/providers/`)**:
   - Created 6 per-feature provider files returning `<BlocProvider>[]` to prevent merge conflicts during parallel execution:
     - `history_providers.dart`: `historyBlocProviders` (Plan 03.1-08)
     - `bodyweight_providers.dart`: `bodyweightBlocProviders` (Plan 03.1-09)
     - `home_providers.dart`: `homeBlocProviders` (Plan 03.1-11)
     - `stats_providers.dart`: `statsBlocProviders` (Plan 03.1-12)
     - `checkin_providers.dart`: `checkinBlocProviders` (Plan 03.1-06)
     - `settings_providers.dart`: `settingsBlocProviders` (Plan 03.1-07)
   - Spread all 6 lists inside `MultiBlocProvider` in `lib/app/app.dart`.

3. **Weight Decimals Listener (`lib/app/app.dart`)**:
   - Initialized `setWeightDecimals(widget.gymStateCubit.state.wdec == 2 ? 2 : 1)` in `_OpenExerciseAppState.initState`.
   - Wrapped shell UI in `BlocListener<GymStateCubit, GymState>` listening when `a.wdec != b.wdec` to dynamically update `setWeightDecimals` across the app (mirroring `App.jsx:85`).

4. **Real Header Entry Points (`HomeScreen`, `StatsScreen`)**:
   - **`HomeScreen` (`lib/features/home/view/home_screen.dart`)**:
     - Header: 'openGym', subtitle with long date (e.g. 'Tuesday, 29 September'), trailing gear `AppIconButton` navigating to `/settings`.
     - At the gym / Check in card: blue QR icon disc, 'At the gym' subtitle, 'Check in' title, chevron, navigating to `/checkin`. Conditionally rendered only when `checkIn != false`.
   - **`StatsScreen` (`lib/features/stats/view/stats_screen.dart`)**:
     - Header: 'Stats', subtitle 'Progress & history', trailing history `AppIconButton` navigating to `/history`.
   - Scaffold screens (`HistoryScreen`, `CheckInScreen`, `SettingsScreen`) with corresponding back chevrons returning to `/stats` and `/home`.

5. **Shared Presentation Components**:
   - **`WorkoutRowTile` (`lib/features/history/view/widgets/workout_row_tile.dart`)**:
     - Ported from `sheets.jsx:1789-1802`.
     - 34x34 glyph disc with routine emoji lookup via `glyphOf`.
     - Subtitle joining long date, duration (`durPart`), completed sets (`engine.history.setsDone(workout)` per JS-04), and formatted volume (`fmtVol`).
     - Trailing trophy PR badge (`{n} PR`) when `workout.prs` is non-empty, followed by chevron.
   - **`Heatmap` (`lib/core/ui_kit/heatmap.dart`)**:
     - Ported from `Heatmap.jsx` and `index.css:1182-1197`.
     - Uses `HeatmapDayInfo` input model (no domain aggregation inside the widget per JS-04).
     - 53 columns (wk 0..52) of 7 days, cells 11x11 with radius 3 and 3px gaps.
     - Horizontal auto-scroll to `maxScrollExtent` on mount.
     - Month headers (showing `kMonths[mo]` when `mo != lastMonth && colStart.day <= 7 && wk < 51`).
     - Day labels (Mon/Wed/Fri placed at `weekDayOffset`).
     - Shading ramp l0..l4 with accent Color.lerp (30%, 55%, 78%, 100%), today accent ring (1.5px), future cell opacity (0.3).
     - Legend: 'Less time' l0..l4 'More time'.
     - Interactive tooltips and `onDay` callback.
     - Exported from `lib/core/ui_kit/ui_kit.dart`.
