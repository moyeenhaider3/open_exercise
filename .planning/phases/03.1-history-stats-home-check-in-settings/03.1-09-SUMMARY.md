# Plan 03.1-09 Summary: Bodyweight BLoC, BwSheet, GoalSheet, and bwDeltaColor

## Overview
Implemented the body-weight logging and goal management infrastructure shared across Home and Stats. Built `BodyweightBloc` for mutating bodyweight entries and target weight, standalone `showBwSheet` for logging bodyweight and managing recent entries, `showGoalSheet` for target weight goal setting/clearing with bridge proximity hints, and the `bwDeltaColor` indicator helper.

## Key Deliverables

1. **BLoC & Event Layer**:
   - **`lib/features/bodyweight/bloc/bodyweight_event.dart`**: Sealed hierarchy with `BodyweightLogged(value)`, `BodyweightEntryDeleted(d)`, `BodyweightGoalSet(value)`, `BodyweightGoalRemoved()`, and `BodyweightGymStateChanged(state)`.
   - **`lib/features/bodyweight/bloc/bodyweight_state.dart`**: `BodyweightState` with one-shot signals: `BodyweightInvalid`, `BodyweightSaved(value)`, `BodyweightGoalSaved(value)`, and `BodyweightGoalCleared`.
   - **`lib/features/bodyweight/bloc/bodyweight_bloc.dart`**: Sequential event handler mutating `GymStateCubit` via `mutate`. Rounds weights to 1 decimal place (`(value * 10).round() / 10.0`), rejects values `<= 0` with `BodyweightInvalid`, replaces or adds today's entry (`todayIso()`) with sorted dates, deletes entries by date, sets `targetW`, and explicitly clears `targetW` to `null`.
   - **`lib/app/providers/bodyweight_providers.dart`**: Registered `BodyweightBloc` with `gymState` from `GymStateCubit`.

2. **Delta Color Helper (`lib/features/bodyweight/view/bw_delta_color.dart`)**:
   - `bwDeltaColor(BuildContext context, num? delta, num currentW, num? targetW)`: Directly ports `sheets.jsx:550-555`. Returns `palette.muted` for missing/zero delta, `Theme.onSurface` when no target exists, and `palette.acc` or `palette.red` based on whether the delta moves toward the target.

3. **Standalone BwSheet (`lib/features/bodyweight/view/bw_sheet.dart`)**:
   - `showBwSheet(BuildContext context)`: Opens non-required bodyweight logging sheet with header `Log body weight`, date display `${t('Today')}, ${fmtDate(todayIso(), long: true)}`, `WeightInput` seeded from `lastBW(gymState)?.w ?? 70`, and primary `Save` button.
   - Listens to `BodyweightBloc` signals to display toasts (`Weight saved` / `Enter a valid weight`) and pop sheet on save.
   - Lists up to 3 most recent weigh-ins newest-first with formatted date, bold value and unit, and trash button dispatching `BodyweightEntryDeleted`.

4. **Goal Sheet (`lib/features/bodyweight/view/goal_sheet.dart`)**:
   - `showGoalSheet(BuildContext context)`: Opens target weight goal sheet with header `Target weight`, explanation copy, `WeightInput` seeded from `targetW`, else `lastBW`, else 70.
   - Primary `Save goal` button dispatching `BodyweightGoalSet`.
   - Listens to `BodyweightGoalSaved` to close and toast `Goal set: {n} {unit}` plus `({gap} to go)` computed via `engine.viewAgg.bwGoal`.
   - Danger `Remove goal` button dispatching `BodyweightGoalRemoved`, closing, and toasting `Goal removed`.
