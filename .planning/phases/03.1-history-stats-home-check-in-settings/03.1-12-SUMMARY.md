## Changes Implemented

### 1. Stats BLoC State Management
- `lib/features/stats/bloc/stats_event.dart`:
  - `StatsEvent` sealed hierarchy.
  - `StatsRangeChanged(int days)`: Bodyweight range selection (30, 90, 365, 0).
  - `StatsExerciseSelected(String id)`: Exercise selection for progress curve.
  - `StatsExerciseMetricChanged(String metric)`: Metric toggle (`top`, `e1rm`, `effort`).
  - `StatsEffortWindowChanged(int days)`: Effort timeframe window (30, 90, 365, 0).
  - `_StatsGymStateChanged(GymState state)`: Private stream subscription event.
- `lib/features/stats/bloc/stats_state.dart`:
  - `StatsReady` immutable state holding range selections, derived `StatsTiles`, `streakWeeks`, `lastBW`, `Map<String, HeatmapDayInfo>`, `bwPoints`, `hasEffort`, `kind`, `hd`, effort summary/weeks/histogram, and `ExerciseProgress` aggregates.
- `lib/features/stats/bloc/stats_bloc.dart`:
  - Listens to `GymStateCubit` stream.
  - Computes display names map from `ExerciseCatalogue` for exercise progress.
  - Delegates all metric, chart point, and summary calculations to bridged JS engine calls.
- `lib/app/providers/stats_providers.dart`:
  - Registered `StatsBloc` in the DI tree.

### 2. Stats UI Components
- `lib/features/stats/view/widgets/effort_card.dart`:
  - Period selector (`30d`, `90d`, `1Y`, `All`).
  - Metric headline: average effort in RIR/RPE scale, hard sets percentage, rated of finished sets count.
  - Effort switched-off warning banner if effort tracking is disabled in settings.
  - Week-by-week line chart with scale inversion for RIR.
  - Where-the-sets-land distribution rows with scaled bars and percentage labels.
- `lib/features/stats/view/widgets/exercise_progress_card.dart`:
  - Exercise selector `SelectRow` with searchable picker and best performance indicator.
  - Metric toggle segmented control (`Top set`, `Est. 1RM`, `Effort`).
  - Interactive line chart with RIR fullness markers.
  - Last 5 workout session breakdown using `setLabel`.
  - Explanatory captions for 1RM estimations and RIR marker meanings.
- `lib/features/stats/view/stats_screen.dart`:
  - Top header with History and Calendar shortcut icons.
  - 2x2 metric tiles: Workouts, This month, Week streak, Weight 30d (with delta coloring).
  - Activity heatmap (53 weeks by time trained, scrolled to today).
  - Bodyweight card with range toggle (1M, 3M, 1Y, All), goal line, Log and Goal sheets.
  - Recent Workouts section showing up to 6 latest workouts with 'All {n}' navigation to `/history`.
