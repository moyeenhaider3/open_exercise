# Plan 03.1-05 Summary: Log a Past Workout (Backfill Flow & Sheets)

## Overview
Implemented openGym's complete "Log a past workout" (backfill) flow end-to-end. Created `LogPastWorkout` and `SameDayChoice` modal sheets, wired `WorkoutBackfillStarted` event to `WorkoutBloc`, branched session completion via the bridged `completeBackfill`, updated the active-workout view to display date strings and suppress rest timers, and validated all UI-05 / UI-07 / JS-04 architectural invariants.

## Key Deliverables

1. **Model Extras (`lib/core/models/model_extras.dart`)**:
   - Replaced boolean `backfill` getter with structured `Map<String, Object?>? get backfill` matching openGym's `{durationMin, replaceId}` dictionary shape.
   - Added `bool get isBackfill`, `num? get backfillDurationMin`, and `String? get backfillReplaceId`.

2. **Event & BLoC Wiring (`lib/features/workout/bloc/`)**:
   - **`workout_event.dart`**: Added `WorkoutBackfillStarted` (`iso`, `time`, `durationMin`, `routineId`, `replaceId`) citing `sheets.jsx:1890-1907`.
   - **`workout_bloc.dart`**:
     - Factored routine entry construction into private `_buildSessionEntries` helper.
     - Handled `WorkoutBackfillStarted`: calculates start epoch via `_engine.backfill.backfillStart(iso, time)`, sets `backfill` extra map and `bw: null`, resets `_progressHighWater`, and emits `WorkoutStartedSignal`.
     - In `_onFinishConfirmed`: branched on `result.past` to insert via `_engine.backfill.completeBackfill(st.workouts, st.active!, result.workout)` and omit `exWeights` updates, leaving historical progression weights intact.

3. **Active Workout View (`lib/features/workout/view/active_workout_view.dart`)**:
   - For backfilled workouts (`active.isBackfill`): replaces `_Elapsed` ticker with `fmtDate(active.d, long: true)`.
   - Displays muted banner `t('Logging a past workout — no rest timers.')` above the exercise entries.

4. **Sheets (`lib/features/history/view/sheets/log_past_workout_sheet.dart`)**:
   - `showLogPastWorkoutSheet(context)`: checks for active workout and rejects with toast `'Finish the current workout first.'` if in progress.
   - Form inputs:
     - Date picker starting at yesterday and bounded to today.
     - Time picker defaulting to 18:00.
     - Duration stepper defaulting to 45 min, clamped to integers $\ge 1$.
     - Routine picker (Freestyle + routines).
   - Validates date $\le$ today with toast `'Pick a day up to today'`.
   - Queries `workoutsOn(state, date)`:
     - If empty: initiates backfill immediately.
     - If existing: opens `SameDayChoice` centered dialog offering danger `'Replace'` (or `'Replace · <name>'` for multiple), primary `'Add as second workout'`, and ghost `'Cancel'`.
