## Changes Implemented

### 1. Home BLoC State Management
- `lib/features/home/bloc/home_event.dart`:
  - `HomeEvent` sealed hierarchy.
  - `HomeWeekOffsetChanged(int delta)` for stepping between weeks.
  - `_HomeGymStateChanged(GymState state)` private event for reactive emissions.
- `lib/features/home/bloc/home_state.dart`:
  - `HomeStripDay` value object representing the 7 days of the currently selected week.
  - `HomeReady` containing week offset, today ISO, routines, overrides, workout status, last bodyweight, home view aggregate, streak weeks, and strip days.
- `lib/features/home/bloc/home_bloc.dart`:
  - Subscribes to `GymStateCubit` stream.
  - Computes strip days using `weekDayOffset` and `weekStartOf` while delegating all domain logic to `engine.viewAgg.homeView`, `engine.history.streakWeeks`, `engine.history.nextTrainingDay`, `engine.history.effectiveRoutines`, and `engine.history.lastBW`.
- `lib/app/providers/home_providers.dart`:
  - Registered `HomeBloc` in the application provider hierarchy.

### 2. Home Widgets & Screen Layout
- `lib/features/home/view/widgets/week_card.dart`:
  - Week navigation header with "This week" or date range formatting (`{d} {Mon} – {d} {Mon}`).
  - 7 day cells with uppercase day names, day number, and status indicator dots. Tapping opens `showDayOverrideSheet`.
  - Today row displaying icon disc, session status, reschedule badge, next planned session, and trailing action tag ('Resume', 'Done', 'Start', or plus icon).

- `lib/features/home/view/home_screen.dart`:
  - Assembled gear button header, `WeekCard`, gym check-in card, Welcome card (for empty plans), `BodyweightCard`, and streak card.
  - Streak card displays flame icon, week streak, weekly session count, total workouts, and calendar icon; tapping opens `showCalendarSheet`.
