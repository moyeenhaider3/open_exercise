# Plan 03.1-06 Summary: Check-in Screen (qr_flutter, CheckInBloc, Card Management)

Built `CheckInBloc`, the `moveGymCard` data helper, `EditCardSheet`, and `CheckInScreen` featuring a `PageView.builder` card rail with pagination dots, rename, delete confirmation, and slot reordering.

     - `CheckInActiveCardChanged(id)`: tracks active card without duplicate mutations.
   - Registered `BlocProvider<CheckInBloc>` in `checkinBlocProviders`.

   - **`checkin_screen.dart`**:
     - Header with back navigation to `/home`, title `'Check in'`, and dynamic subtitle (`'Show this at the gym'` or `'Add your gym card'`).
     - `PageView.builder` rail initialized to `lastGymCardId`.
     - Card face:
       - Header row with edit pencil button, centered label, and red trash button.
       - Delete confirmation via `showConfirmSheet` (`'Remove this card?'`, danger variant).
       - White QR plate rendering `QrImageView` (230x230).
       - Monospace/tabular-figure raw code value underneath.
       - Reorder row (`chevronLeft`, `'i / n'`, `chevronRight`) with opacity dimming at ends.
     - Pagination dots below the rail (`surface3` inactive, `acc` active).
