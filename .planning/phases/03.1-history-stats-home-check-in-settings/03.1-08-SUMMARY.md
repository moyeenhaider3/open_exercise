# Plan 03.1-08 Summary: History Screen, Workout Detail, Calendar, and Day Override

## Overview
Implemented the complete History feature and the three shared modal sheets (WorkoutDetail, Calendar, and DayOverride). Ported views and sheets directly from openGym's `History.jsx`, `sheets.jsx:DayOverride`, `sheets.jsx:WorkoutDetail`, and `sheets.jsx:Calendar`. Added `HistoryBloc` for session note editing and workout deletion, and extended `PlanBloc` with `PlanDayOverrideSet` for single-day plan overrides.

## Key Deliverables

1. **BLoC & Event Layer**:
   - **`lib/features/history/bloc/history_event.dart`**: `HistoryWorkoutNoteSaved(workoutId, text)` and `HistoryWorkoutDeleted(workoutId)`.
   - **`lib/features/history/bloc/history_state.dart`**: `HistoryInitial` base state.
   - **`lib/features/history/bloc/history_bloc.dart`**: Sequential event handler modifying `GymStateCubit` via `mutate`. Truncates note text to `engine.history.noteMax` and handles clean removal when empty.
   - **`lib/app/providers/history_providers.dart`**: Registered `HistoryBloc` using `gymStateCubit` and `engine`.
   - **`lib/features/plan/bloc/plan_event.dart` & `plan_bloc.dart`**: Added `PlanDayOverrideSet(iso, value)` event and `_onDayOverrideSet` handler mutating `dayPlan`.

2. **Day Override Sheet (`lib/features/plan/view/sheets/day_override_sheet.dart`)**:
   - `showDayOverrideSheet(BuildContext context, String iso)`: Displays long-formatted date, weekly plan name (derived via `engine.sessionMerge.deriveSessionName` with orange `changed for this day` indicator when overridden), routine options with exercise counts and checkmarks matching `effectiveRoutineIds`, rest day option (`moon` icon), and "Back to weekly plan" (`reset` icon) when active override exists.
   - Dispatches `PlanDayOverrideSet` and triggers openGym toast notifications.

3. **Workout Detail Sheet (`lib/features/history/view/sheets/workout_detail_sheet.dart`)**:
   - `showWorkoutDetailSheet(BuildContext context, Workout w)`: Header displays date, duration, volume, and bodyweight.
   - Renders entries with `ExerciseThumb`, capitalized name, PR badge, completed set labels from `setLabel`, and yellow flagged pinned notes.
   - Routines grouped via `engine.viewAgg.workoutDetailGroups`: renders section header with routine glyph, name/Freestyle, set count, and group volume.
   - Multiline session note `TextField` capped at `noteMax` that flushes and saves on blur and on sheet dismissal (`dispose()`).
   - Confirmed destructive deletion via `showConfirmSheet` with danger styling, dispatching `HistoryWorkoutDeleted`.

4. **Calendar Sheet (`lib/features/history/view/sheets/calendar_sheet.dart`)**:
   - `showCalendarSheet(BuildContext context, {String? start})`: Month navigator with chevron controls and month/year title.
   - Month summary line calculated via `engine.viewAgg.calendarMonth(gymState, y, mo)` displaying workout count, duration, and volume.
   - `GridView.builder` rendering week day headers, start offset blanks, and day cells with trained (`acc`), rescheduled (`orange`), and planned (`dim`) dot indicators plus today border ring.
   - Day tap routing: empty days open `showDayOverrideSheet`, single workouts open `showWorkoutDetailSheet`, multiple workouts open picker sheet with `WorkoutRowTile`.
   - Calendar legend and interaction hint matching openGym.

5. **History Screen (`lib/features/history/view/history_screen.dart`)**:
   - `HistoryScreen`: `CustomScrollView` with navigation back to `/stats`, title and workout count subtitle.
   - Full-width button with `plus` icon triggering `showLogPastWorkoutSheet(context)`.
   - `SliverList.builder` rendering `WorkoutRowTile` items newest-first (`count - 1 - index`).
   - `EmptyState` with `history` icon and "No workouts yet." when empty.
