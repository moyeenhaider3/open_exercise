It returns SizedBox.shrink when `ex.gif == null`, or when minimizable and S.gifSize == 'off' (read through `BlocSelector<GymStateCubit, GymState, String?>`). Mini mode applies when minimizable and gifSize == 'mini'. showGif = playing && failed == null. The image is `Image.network(showGif ? gifSrc : imgSrc, gaplessPlayback: true, errorBuilder: …)`; the errorBuilder advances failed ('gif' when the GIF failed, otherwise 'all') in a post-frame callback. failed == 'all' shows the dumbbell tile. Tap: if failed, clear it and play; otherwise toggle playing. The minimize/expand toggle dispatches `MediaSizeToggled` to ExercisesBloc and shows t('Expand')/t('Minimize') with its icon. The 'tap to pause' / 'tap to play' hint shows when not mini and not failed. Semantics label = exerciseNameFor(ex).
    `class ExerciseThumb` ports Thumb: the 'dumbbell' tile when there is no img, otherwise `Image.network(imgSrc, cacheWidth: …)` at the thumb size, with an errorBuilder that shows the tile.
    Caching: use Flutter's default `PaintingBinding.instance.imageCache` (in-memory LRU), with no disk-cache package (UI-02 says "cached in memory"; a disk cache would be a new unmandated dependency). Document this in the file header.
