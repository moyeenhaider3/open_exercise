## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-13 | Denial of Service | searchExercises on huge pasted query | mitigate | Tokens split on whitespace; nearWord bails early on length difference > 1 (ported rule); corpus cached per exercise so a keystroke is O(catalogue × tokens) |
| T-03-14 | Tampering | ExerciseDef from persisted customEx | mitigate | Unknown/wrong-typed keys stay in extra (passthrough); lookups of unknown ids return exOr's placeholder instead of throwing |
| T-03-15 | Spoofing/Tampering | Media URL | mitigate | Base URL is a compile-time const pinned to a commit SHA; only the catalogue's img/gif file names are appended (no user input in the URL) |
| T-03-16 | Information Disclosure | CDN fetch | accept | Same public dataset openGym's own mobile build fetches; no user data in requests |
