    Write `tool/js/gen-icons.mjs` plus the wrapper `tool/gen_icons.sh` (SPDX headers). The generator transforms ../openGym/frontend/src/components/Icon.jsx with the esbuild already in tool/js/node_modules, using a custom JSX factory that records `{type, props}` instead of rendering React. It then evaluates the module in Node, reads `P` (including the alias assignments) and writes `lib/core/ui_kit/icons/app_icon_data.g.dart`. That file holds a header comment "GENERATED by tool/gen_icons.sh from ../openGym/frontend/src/components/Icon.jsx — do not edit" with the source file's sha256, then `const Map<String, List<IconElement>> kIconData`. Each IconElement records its type (path/rect/circle/ellipse/line/polyline/polygon), numeric attributes, the `d` string, and any fill/stroke/opacity overrides. It also writes `const List<String> kIconNames` in openGym's ICON_NAMES order.
    `lib/core/ui_kit/icons/app_icon.dart`: `class AppIcon extends StatelessWidget { const AppIcon(this.name, {super.key, this.size, this.color}); }`. The default size is the ambient `IconTheme` size and the default colour is `IconTheme.of(context).color` (openGym's currentColor). Painting uses a `CustomPainter` with a 24x24 viewBox scaled to size, stroke width 1.7 (or the stylesheet value), `StrokeCap.round`/`StrokeJoin.round`, no fill unless the element declares one. `path` elements go through `parseSvgPathData`. Other primitives convert to Path geometry (addRRect, addOval, moveTo/lineTo). This is shape geometry, not domain math. An unknown name renders `SizedBox.shrink()`, mirroring Icon.jsx's `if (!d) return null`. Wrap the output in `ExcludeSemantics` (aria-hidden).
