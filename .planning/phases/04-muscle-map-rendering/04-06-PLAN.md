    `class MusclesBloc extends Bloc<MusclesEvent, MusclesState>`:
    - Constructor `({required GymStateCubit gymState, required ExerciseCatalogue catalogue, required JsEngineService engine})`, a single `on<MusclesEvent>(_onEvent, transformer: _sequential())`, and it adds MusclesStarted. MusclesStarted subscribes to gymState.stream; close() cancels the subscription.
    - Muscle index cache: `_index = engine.muscleView.muscleIndex(s)` is computed on start and recomputed only when `s.customEx` differs from the customEx used last time (Equatable `==` / `listEquals`). This avoids ~1300 per-exercise bridge calls on every keystroke (T-04-05).
    - `_compute(...)`, transcribing MuscleExplorer.jsx:28-44 in order:
      - `profile = activeProfile(s)`
      - `catalog = (profile != null && !showAll) ? all.where(exAvailable) : all`, where `all = catalogue.allExercises(s)`
      - `counts[m] = catalog.where((e) => (_index[e.id]?[m] ?? 0) != 0).length` for each m in `engine.muscles.muscles`. This is JS truthiness: weight 0 or absent means false.
      - `targeted = selected == null ? [] : catalog.where(weight(selected) != 0)`
      - `base = searchExercises(targeted.where((e) => bp.isEmpty || e.bp == bp).toList(), q)`
      - `eqOpts = catalogue.equipmentOf(base)`; `eqOn = eqOpts.contains(eq) ? eq : ''`
      - `results = sortFavouritesFirst(eqOn.isNotEmpty ? base.where((e) => e.eq == eqOn).toList() : base, s)`
      - `primaryIds` = ids among the first `shown` results whose weight for selected `== 1` ('Primary target' vs 'Also trains').
      - `bestWeights` = `engine.history.bestWeightFor` for the first `shown` results, keeping > 0 only.
      - `favIds`, `body = s.body`, `muscleNames = engine.muscles.muscleName`, `muscleOrder = engine.muscles.muscles`.
    - These are list filters and counts over bridged weights. No weights or loads are computed in Dart, and there is no dart:math import.
