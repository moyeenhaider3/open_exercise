Passthrough contract (defined by this plan, used by Plans 01-04 and 01-06):
- A known field is stored in its typed Dart field only when present AND of the expected JSON type.
- Absent keys stay absent. Explicit nulls, wrong-typed values and unknown keys go into `extra` (Map<String, Object?>) unchanged.
- toJson() = {...extra, ...non-null typed fields}, so output == input for any input map.

    lib/core/models/json_passthrough.dart: class JsonReader wrapping a source Map<String, Object?> and a mutable extra map. Constructor JsonReader(Map<String, Object?> source, {Set<String> known}) copies into extra every key not in known. Typed read methods: string(key), integer(key) (accepts int, and a double with no fractional part stays in extra rather than being coerced; do not coerce), number(key) returning num, boolean(key), map(key) returning Map<String, Object?>, list(key) returning List<Object?>, and objectList<T>(key, T Function(Map<String, Object?>) parse) which returns a typed list only if every element is a Map, else null (whole value goes to extra). Rule for every read: key absent -> null and nothing added; key present with the expected type -> typed value; key present with null or another type -> null and the original value put into extra under the same key. Use `is` checks and Dart 3 patterns only, never `as` casts (strict-casts is on). Expose `Map<String, Object?> get extra` as an unmodifiable copy. Also export a top-level helper `Map<String, Object?> emit(Map<String, Object?> extra, Map<String, Object?> typed)` that returns {...extra, ...typed-with-null-values-removed}, preserving extra's key order first.
