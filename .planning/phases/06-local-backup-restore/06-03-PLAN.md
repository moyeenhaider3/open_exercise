## Tasks

### Task 1: BackupFolderService

Create `lib/core/backup/backup_folder_service.dart`:

Platform-abstracted service for folder operations:

```dart
final class BackupFolderService {
  BackupFolderService({
    required BackupSettingsDao settingsDao,
    required BackupBookmarkChannel bookmarkChannel,  // no-op on Android
  });

  /// Opens the system folder picker.
  /// Android: SAF tree picker → persisted URI via file_picker AndroidSAFOptions.
  /// iOS: folder doc picker → security-scoped bookmark via BackupBookmarkChannel.
  /// Returns the display folder name, or null if cancelled.
  Future<String?> pickFolder();

  /// Writes [content] as [fileName] into the previously chosen folder.
  /// Android: SAF DocumentFile create/overwrite.
  /// iOS: resolve bookmark, write, stop accessing.
  /// Returns true on success.
  Future<bool> writeFile(String fileName, String content);

  /// Checks if the configured folder is still accessible.
  /// Returns false if permission revoked, folder deleted, or bookmark stale.
  Future<bool> isFolderAccessible();
}
```

Platform detection: use `dart:io Platform.isAndroid / Platform.isIOS`.

Android path: `file_picker` `getDirectoryPath()` with SAF options → store URI in
`BackupSettingsDao`. Write via `AndroidSAFHandle` or `File` operations on the SAF URI.

iOS path: `file_picker` `getDirectoryPath()` → pass path to `BackupBookmarkChannel.createBookmark()`
→ store Base64 bookmark in `BackupSettingsDao`. To write: `resolveBookmark()` →
`File(resolvedPath).writeAsString()` → `stopAccessing()`.

### Task 2: BackupRepository

Create `lib/core/backup/backup_repository.dart`:

```dart
final class BackupRepository {
  BackupRepository({
    required GymStateRepository gymStateRepository,
    required BackupFolderService folderService,
    required BackupSettingsDao settingsDao,
    required String uid,
  });

  /// Write today's backup to the chosen folder.
  /// Returns a BackupResult (success/failure + message).
  Future<BackupResult> backupNow();

  /// Export to share sheet (D-11): write to cache, open share_plus.
  Future<BackupResult> exportToShareSheet(Rect? shareOrigin);

  /// Whether a backup folder is configured.
  Future<bool> isFolderConfigured();

  /// Pick a new backup folder. Returns the folder display name, or null.
  Future<String?> pickFolder();

  /// Current backup settings (folder name, last backup time, auto enabled).
  Future<BackupSettings> getSettings();

  /// Toggle auto-backup (also updates GymState.autoBackup via callback).
  Future<void> setAutoBackupEnabled(bool enabled);
}
```

`backupNow()` flow:
1. `gymStateRepository.exportState(uid)` → raw doc map
2. `JsonEncoder.withIndent('  ').convert(doc)` → JSON string
3. File name: `'opengym-backup-${_todayIso()}.json'`
4. `folderService.writeFile(fileName, json)` → success/failure
5. `settingsDao.updateLastBackupAt(DateTime.now())` on success
6. Return `BackupResult`

`exportToShareSheet()` flow:
1. Same JSON as above
2. Write to `getTemporaryDirectory() / fileName`
3. `SharePlus.instance.share(ShareParams(files: [XFile(tempPath)], sharePositionOrigin: shareOrigin))`
4. Return result
