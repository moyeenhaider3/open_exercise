## Tasks

### Task 1: New SettingsBloc events

Add to `settings_event.dart`:

```dart
/// User tapped "Import backup" and file picker returned content.
final class SettingsImportBackupRequested extends SettingsEvent { ... }

/// User confirmed the import in the danger sheet.
final class SettingsImportBackupConfirmed extends SettingsEvent {
  const SettingsImportBackupConfirmed(this.state);
  final GymState state;
}

/// User tapped "Export backup (JSON)".
final class SettingsExportBackupRequested extends SettingsEvent {
  const SettingsExportBackupRequested({this.shareOrigin});
  final Rect? shareOrigin;
}

/// User tapped "Back up now".
final class SettingsBackupNowRequested extends SettingsEvent { ... }

/// User tapped "Backup folder" to pick/change folder.
final class SettingsBackupFolderRequested extends SettingsEvent { ... }

/// User toggled the auto-backup switch.
final class SettingsAutoBackupToggled extends SettingsEvent {
  const SettingsAutoBackupToggled(this.enabled);
  final bool enabled;
}
```

### Task 2: SettingsBloc handlers

Add handlers in `settings_bloc.dart`:

- `_onImportBackupConfirmed`: calls `_gymState.replaceState(event.state)`, then
  `_gymState.flush()`, then emits success state
- `_onExportBackupRequested`: calls `_backupRepository.exportToShareSheet(event.shareOrigin)`
- `_onBackupNowRequested`: calls `_backupRepository.backupNow()`, emits result
- `_onBackupFolderRequested`: calls `_backupRepository.pickFolder()`, refreshes settings
- `_onAutoBackupToggled`: updates `GymState.autoBackup` via `_gymState.update(...)` and
  calls `_backupRepository.setAutoBackupEnabled(event.enabled)`

SettingsBloc constructor: inject `BackupRepository` and `BackupImportService`.

### Task 4: Data section UI

Rewrite `data_section.dart` with D-12 row order:

1. **Load starter plan** — existing, unchanged
2. **Import backup** — icon `upload`, tint blue. Taps → file picker via `BackupImportService`,
   then show confirm sheet (D-16: "Import backup?" / "This replaces all current data with the
   backup file." / danger "Import" button), then dispatch `SettingsImportBackupConfirmed`
3. **Export backup (JSON)** — icon `download`, tint blue. Taps → dispatch `SettingsExportBackupRequested`
   with `sharePositionOrigin` for iPad
4. **Backup folder** — icon `folder`, tint blue. Subtitle: folder name if set, else "Not set".
   Below: "Last backup: <relative time>" or "Never". Taps → dispatch `SettingsBackupFolderRequested`
5. **Auto-backup** switch — icon `history`, tint blue. Subtitle: D-12 description from openGym.
   `Switch` checked = `backupSettings.autoBackupEnabled && hasFolderConfigured`. Disabled when
   no folder configured. onChange → dispatch `SettingsAutoBackupToggled`
6. **Back up now** — icon `save`, tint blue. Disabled when no folder configured.
   Taps → dispatch `SettingsBackupNowRequested`
7. **Reset everything** — existing, unchanged (stays last)
