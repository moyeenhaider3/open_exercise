2. First-workout folder prompt (D-02): "Choose a backup folder" after the first finished workout
3. Folder-unavailable snackbar (D-04): one-time warning on launch if the folder is gone

## Tasks

### Task 1: Fresh-install restore offer (D-14)

Create `lib/core/backup/fresh_install_check.dart`:

```dart
/// Checks if this is a fresh install (no workouts, no routines) and shows
/// the "Restore from a backup?" sheet.
Future<void> freshInstallCheck(BuildContext context) async { ... }
```

The sheet has:
- Title: "Restore from a backup?"
- Body: "If you have a backup from openGym or this app, you can restore it now."
- "Pick file" button → runs BackupImportService.pickBackupFile → validateAndPrepare →
  confirm sheet (D-16) → GymStateCubit.replaceState → "Backup imported" toast
- "Start fresh" button → dismisses

Call from `app.dart` after the initial state load, or from `shell_page.dart` in the first
`initState` / `didChangeDependencies`.

Detection: check `GymStateCubit.state.workouts` is empty and `routines` is empty.

### Task 2: First-workout folder prompt (D-02)

In `workout_bloc.dart`, after `_onFinishConfirmed` completes successfully:

Check if this is the user's first workout (workouts was empty before, now has one).
If so, emit a state/side-effect that tells the UI to show a "Choose a backup folder" sheet.

The sheet:
- "Your first workout is saved! Choose a folder to back up your data."
- "Choose folder" button → opens BackupFolderService.pickFolder → stores settings →
  enables auto-backup
- "Skip" button → dismisses. User can always set it later in Settings.

Important: the prompt must NOT block the finish summary. It appears after the finish
summary is dismissed. Use a post-frame callback or a dedicated navigation event.

### Task 3: Folder-unavailable snackbar (D-04)

In `app.dart` on startup (after state load):

1. Load `BackupSettings` via `BackupSettingsDao`
2. If a folder is configured, check `BackupFolderService.isFolderAccessible()`
3. If not accessible, show a one-time snackbar: "Backup folder unavailable — choose again in Settings"
4. Track "shown this launch" with a simple bool flag — don't show again on resume

Also: `data_section.dart` should show a warning-styled Backup folder row when the folder
is inaccessible (from Plan 05, but coordinate here).
