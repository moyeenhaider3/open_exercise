### Task 1: BackupImportService

Create `lib/core/backup/backup_import_service.dart`:

```dart
final class BackupImportService {
  /// Opens the system file picker for .json files.
  /// Returns the raw file content as a String, or null if cancelled.
  Future<String?> pickBackupFile();

  /// Validates and prepares a GymState from raw backup JSON.
  /// Returns ImportResult.success with the prepared state, or ImportResult.failure with reason.
  ImportResult validateAndPrepare(String jsonContent);
}

sealed class ImportResult {
  const ImportResult();
}
final class ImportSuccess extends ImportResult {
  const ImportSuccess(this.state, this.fileName);
  final GymState state;
  final String? fileName;
}
final class ImportFailure extends ImportResult {
  const ImportFailure(this.reason);
  final String reason;
}
```

`pickBackupFile()` flow:
1. `FilePicker.platform.pickFiles(type: FileType.custom, allowedExtensions: ['json'])`
2. Read file bytes → decode UTF-8 → return string

`validateAndPrepare()` flow:
1. `jsonDecode(content)` — catch FormatException → "Import failed: invalid JSON"
2. Check `data is Map<String, dynamic>` — else failure
3. Check `data.containsKey('workouts') && data.containsKey('routines')` — else
   "Import failed: not an openGym backup" (matches openGym error exactly)
4. Overlay on kDefaultState: `Map<String, Object?>.from(kDefaultState)..addAll(data)`
5. `GymState.fromJson(overlaid)` — catch any parse error
6. Return `ImportSuccess(state, fileName)`
