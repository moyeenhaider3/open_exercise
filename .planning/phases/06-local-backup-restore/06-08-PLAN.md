## Tasks

### Task 1: flutter analyze

```bash
flutter analyze
```

Must pass with no errors.

### Task 2: Round-trip verification script

Create `tool/backup_roundtrip.sh`:

1. Export current state via a throwaway `dart run` script → `state_before.json`
2. Import `state_before.json` back into the app
3. Export again → `state_after.json`
4. Diff the two files (strip `_ts` and similar timestamp fields)
5. If diff is empty → PASS. Otherwise → FAIL with the diff.

This verifies D-18 / success criterion 4.

### Task 3: Device walkthrough — Android

On an Android device/emulator:

1. **Fresh install**: verify "Restore from a backup?" sheet appears (D-14)
2. **Start fresh**: sheet dismisses, app starts normally
3. **First workout**: finish a workout, verify folder prompt appears after finish summary (D-02)
4. **Choose folder**: pick a folder via SAF, verify Settings shows the folder name (D-05)
5. **Auto-backup**: check the folder contains `opengym-backup-YYYY-MM-DD.json` (D-06a)
6. **Edit routine, exit**: verify a backup was written (D-06b)
7. **Background app**: verify backup fires if state changed (D-06c)
8. **Settings → Back up now**: verify "Backup saved" snackbar (D-13)
9. **Settings → Export backup (JSON)**: verify share sheet opens (D-11)
10. **Settings → Import backup**: pick a .json file, confirm, verify "Backup imported" (D-16)
11. **Change folder**: tap Backup folder row, pick new folder, verify subtitle updates (D-03)
12. **Remove folder permission**: revoke SAF permission, relaunch, verify snackbar (D-04)
