<objective>
Create the device-local backup settings persistence layer and iOS security-scoped bookmark bridge.

These are the foundational pieces that plans 03-07 depend on: the settings table, the DAO, the
model, and the native iOS bookmark channel.
</objective>

<context>
Decision D-10: folder URI/bookmark and last-backup time are device-local, not in the state document.
Decision D-19: prefer reusing sqflite/AppDatabase.

Existing pattern: `lib/core/db/app_database.dart` has the sqflite schema with migration versions.

iOS security-scoped bookmarks (06-RESEARCH.md): `file_picker` does not expose bookmark
creation/resolution, so a small Method Channel (~30 lines Swift) is needed.

Android SAF persistence is handled by `file_picker` 12+ natively — no Method Channel needed.
</context>

## Tasks

### Task 1: BackupSettings model

Create `lib/core/backup/backup_settings.dart`:

```dart
final class BackupSettings {
  const BackupSettings({
    this.folderUri,
    this.folderBookmark,
    this.folderName,
    this.lastBackupAt,
    this.autoBackupEnabled = true,
  });

  final String? folderUri;       // Android SAF URI string
  final String? folderBookmark;  // iOS Base64 bookmark data
  final String? folderName;      // Display name for Settings row
  final DateTime? lastBackupAt;  // Last successful backup time
  final bool autoBackupEnabled;  // On once folder chosen (D-09)

  bool get hasFolderConfigured => folderUri != null || folderBookmark != null;

  // fromRow / toRow for sqflite
  // copyWith
}
```

### Task 2: AppDatabase migration

Add `backup_settings` table to `app_database.dart`:

```sql
CREATE TABLE IF NOT EXISTS backup_settings (
  id INTEGER PRIMARY KEY DEFAULT 1,
  folder_uri TEXT,
  folder_bookmark TEXT,
  folder_name TEXT,
  last_backup_at INTEGER,
  auto_backup_enabled INTEGER NOT NULL DEFAULT 1,
  CHECK (id = 1)
);
```

Increment the database version and add a migration step.

### Task 3: BackupSettingsDao

Create `lib/core/backup/backup_settings_dao.dart`:

- `Future<BackupSettings> load()` — reads the single row, returns defaults if empty
- `Future<void> save(BackupSettings settings)` — upsert (INSERT OR REPLACE)
- `Future<void> updateLastBackupAt(DateTime time)` — update just the timestamp
- `Future<void> clear()` — delete the row (for testing/reset scenarios)
