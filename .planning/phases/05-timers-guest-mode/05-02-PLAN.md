<objective>
Bridge the two pieces of openGym logic that Phase 5 needs through the JS bundle (JS-04): the rest decisions in `lib/supersetFlow.js` and the reminder-day expansion `buildReminderNotifications` from `lib/mobile.js`.

Purpose: "Timer numbers follow openGym" (D-07) and the core value is identical numbers. Phase 3 hand-ported the navigation parts of supersetFlow.js into `lib/features/workout/data/superset_flow.dart` and explicitly left out the rest functions for Phase 5. This plan runs those rest functions from openGym's JS instead of re-writing them. mobile.js cannot be bundled directly (dynamic `@capacitor/*` imports, `import.meta.env`), so its pure function is transcribed into a shim, following the Phase 4 `muscle-view-shim.js` precedent.
Output: vendored supersetFlow.js, reminder shim, two typed facades, a model, fixtures, dispatch and device parity.
</objective>
