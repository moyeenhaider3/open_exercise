useUI.js semantics to port 1:1 (lines 17-25 and 90-203):
- pageHiddenAt: set when the app goes hidden; each tick computes seenLive = visible && hiddenAt == null, then clears hiddenAt if visible. So the first tick after returning is NOT live.
- startRest(sec, forIdx): stopRest(); return if !(sec > 0); timer = {left: sec, total: sec, endsAt: now + sec*1000, forIdx}; 1 s interval + tick on visibility change.
- tick: left = max(0, round((endsAt - now)/1000)); return if left == timer.left; if left <= 0 { if seenLive { beep(snd,880,0.15); beep(snd,880,0.15,0.25); beep(snd,1320,0.4,0.5); vibrate([200,100,200]); flashTimer() }; toast t('Rest over — next set!') (always); stopRest(); return }; if left <= 3 beep(snd,660,0.1); timer.left = left.
- addRest(sec): no timer -> return; left = timer.left + sec; left <= 0 -> stopRest(); else left, total += sec, endsAt += sec*1000.
- shiftRestOwner(at, delta): if timer.forIdx >= at then forIdx += delta.
- stopRest(): clear interval; if a timer existed cancel the background alert; timer = null.
- startWork(sec, label, onDone): stopWork(); stopRest(); total = max(1, round(sec) || 1); work = {left: total, total, endsAt, label}; same tick; at 0: seenLive -> same beeps/vibrate/flash; then stopWork() and onDone(total). No toast, no notification for work sets.
- finishWorkEarly(): elapsed = max(1, total - left); vibrate(30); stopWork(); onDone(elapsed).
- flashTimer(): only if S.timerFlash; timerFlashId += 1.
- Removing an exercise (Workout.jsx:499-506): stopWork(); if timer.forIdx == idx stopRest() else shiftRestOwner(idx + 1, -1).
- Moving a unit (Workout.jsx:671-686): stopWork(); rest.forIdx remapped to moved.indices.indexOf(rest.forIdx) when >= 0.
Local-notification mapping (replaces pushRestTimer/cancelPushRestTimer, D-06): schedule on app hidden while a rest runs; cancel on app shown and inside every stopRest.

RestTimer.jsx layout + ../openGym/frontend/src/index.css lines 1021-1055 (#timer): surface background, clock 26px weight 600 tabular figures min-width 66, bar 4px surface-3 track with accent fill animating width over 1 s linear. Rest variant: column, head row (clock + bar), actions row (-15s with minus icon, +15s with plus icon, Skip primary pushed to the far edge, min width 84). Work variant: one row, accent hairline border, clock in accent, grow column (label + bar), Cancel, Done (primary, check icon).
TimerFlash.jsx: steps [opposite, original, opposite, original] applied at i*600 ms; cleanup restores the original.
