openGym behaviour to reproduce:
- sound.js beep(enabled, freq, dur, when): no-op when !enabled; `when` delays the tone (seconds).
- sound.js vibrate(p): navigator.vibrate(p); p is a number (ms) or a pattern [on, off, on] -> the vibration package pattern is [0, ...p].
- sound.js setPlayOnSilent(on): 'playback' session (ignores the silent switch, exclusive) when on, browser default ('auto' -> Ambient, obeys the switch) when off; applied whenever S.soundOnSilent loads or changes (App.jsx:67). Off by default (DEF.soundOnSilent = false). Do NOT port unlock()/AudioContext resume (research: Safari-only problem).
- App.jsx:129 useWakeLock(!!S.active && S.keepAwake !== false); lib/wakelock.js re-acquires on every return to foreground and stays silent when the OS refuses (Low Power Mode).
- useUI.js maybeRestNotification: title t('Rest over — next set!'), no body ("it only repeated the title"), tag 'rest-timer'.
- mobile.js: reminder ids REMINDER_ID_BASE + offset (1000..1059) and legacy ids 100..106; title/body come from ReminderJs (plan 05-02). iOS keeps at most 64 pending notifications: 60 reminders + 1 rest fits.

Tones available (05-01): assets/audio/tone_660_100.wav, tone_880_150.wav, tone_1320_400.wav, tone_1040_120.wav, tone_1100_150.wav, tone_1320_300.wav.
