## 4. Key Decisions & Conventions
- **JS-04**: All domain math is delegated to JS via `JsEngineService`; never implement duplicate domain logic in Dart.
- **D-04**: All persisted state modifications go through `GymStateCubit.mutate`.
- **UI-08**: Zero raw `ListView(` constructors; sets and heatmap grids are bounded.
- **Provider Isolation**: Feature Blocs are registered through individual provider files (`lib/app/providers/*_providers.dart`) so screen plans in Waves 2-4 never modify `app.dart` or `app_router.dart`.
- **Zero Test Files**: Project rule strictly forbids creating files in `test/`, `integration_test/`, or `*_test.dart`.
